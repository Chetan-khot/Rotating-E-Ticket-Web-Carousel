# 🎫 Rotating E-Ticket Web Carousel

A responsive web application that displays event e-tickets inside an interactive rotating carousel. Users can browse multiple tickets using smooth animations, making it suitable for event booking systems, travel platforms, movie ticketing, and digital pass management.

---

## ✨ Features

- Interactive rotating ticket carousel
- Smooth navigation between tickets
- Responsive design
- Clean and modern UI
- Lightweight implementation
- Fast loading
- Easy to customize
- Node.js server support

---

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/Chetan-khot/Rotating-E-Ticket-Web-Carousel.git
```

### Navigate to Project

```bash
cd Rotating-E-Ticket-Web-Carousel
```

### Install Dependencies

```bash
npm install
```

### Start Server

```bash
node server.js
```

or

```bash
npm start
```

Open your browser and visit

```
http://localhost:3000
```

(Use the port configured in your `server.js`.)

---

## 🎯 How It Works

1. Launch the application.
2. The carousel displays available e-tickets.
3. Navigate using carousel controls.
4. Tickets rotate smoothly with animations.
5. The interface automatically adapts to different screen sizes.
